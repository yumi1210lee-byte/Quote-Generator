# Quote-Generator 報價單產生器

設計接案用的網頁報價單：左邊填資料，右邊即時看到排好的報價單，可以直接列印或存成 PDF，也能產生分享連結給客戶看。

## 使用方式

直接用瀏覽器打開 `index.html` 即可（不需要安裝任何東西）。

- **範本**：DM設計、影片 logo設計、專輯裝幀設計、空白，從過往報價單整理而來。
- **常用項目**：每個項目分類下方可以從「常用項目」快速加入服務與參考單價（在 `presets.js` 裡修改）。
- **單價**：可填數字，或填區間文字（例如 `12,000 – 18,000`），區間不會計入小計。
- **不計入小計**：用在「第3次起修改費用」這類追加項目。
- **不打折**：用在印刷諮詢這類不適用折扣的項目。
- **折數**：填 `79`、`85` 或 `9`，代表 79 折、85 折、9 折；留空就不打折。
- **我的資料與合作條款**：工作室名稱（報價單大標題）、設計師名稱、匯款帳號、聯絡方式、條款，只存在你自己的瀏覽器，不會進到程式碼裡。
- **儲存**：報價單存在這台瀏覽器；要換電腦可以用「匯出檔案 / 匯入檔案」。
- **複製分享連結**：報價單內容會壓縮在連結裡，客戶打開看到的是唯讀版本，可以自己列印或存 PDF。
- **列印 / 存成 PDF**：檔名會自動帶入「日期_專案_報價」。
